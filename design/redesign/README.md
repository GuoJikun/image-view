## 三条设计原则

1. **外壳交给系统，内容自己画。** 标题栏、窗口按钮、文件对话框、菜单栏都用平台原生能力；窗口内部（工具栏、画布、缩略图条、状态栏）用同一套自绘控件，保证三端观感一致。
2. **中性灰 + 单一强调色。** 只有一种强调色（`#0A7CFF` / 深色 `#0A84FF`），只用于选中、主按钮和进度；其余靠明度层次与 1 px 细线分隔，避免彩色图标堆叠。
3. **画布恒为深色。** 图片是主角：无论浅色还是深色主题，画布都固定 `#1C1C1E`（深色 `#101012`），窗口其余部分是浅灰 chrome。这样图片永远有最大对比度，也不会出现"浅色主题下白色画布把浅色图片吃掉"的问题。

## 版式 A：工具栏模式（推荐默认）

- 顶栏只保留一个 52 px 工具栏：左侧 `打开` + `‹ ›`，右侧 `缩略图` `幻灯片` `排序` `− 百分比 +` `⋯`。
- 中央留白。文件名交给系统标题栏，避免与工具栏重复；进入全屏（系统标题栏消失）后，文件名回到工具栏中央并 3 秒后淡出。
- 全部次级操作（在文件管理器中显示、复制路径、打开日志、主题、快捷键…）收进 `⋯` 与右键菜单。
- 与 Windows Photos / Paint、macOS Preview 的现代做法一致，在 Windows 上是最不违和的一版。

## 版式 B：原生菜单栏

- **Windows**：`muda` 把 Win32 菜单条挂到窗口（标题栏下方 22 px），菜单条随浅/深色主题切换；工具栏保留翻页、缩略图、幻灯片、排序、缩放。
- **macOS**：菜单走屏幕顶部的系统菜单栏（文件 / 编辑 / 显示 / 帮助），窗口内不再重复。
- **Linux**：没有可靠的跨桌面原生菜单条，回落为工具栏 + 右键菜单。
- 建议做成设置项「菜单栏：系统原生 / 只用工具栏」，默认按平台取值（mac 原生、Win/Linux 工具栏），用户可一键对比两种观感。

## 关键规格

| 项 | 值 |
| --- | --- |
| 工具栏 | 高 52，按钮 30×30、圆角 6，图标 17 px、线宽 1.5 |
| 工具栏分组 | 分隔线 1×18，两侧各 12 px |
| 缩放分段控件 | 118×30，圆角 6，中段为白底"值"块 |
| 缩略图条 | 高 88，卡片 76×56、圆角 6、间距 9；选中为外扩 2 px 强调色环 |
| 状态栏 | 高 26，11 px 次文字色；短提示（如"已复制路径"）出现在右侧，4 秒淡出 |
| 空状态 | 中心图标 60×60 + 标题 15 px + 说明 12 px + 强调色主按钮 |

### 色板

浅色：chrome `#F6F6F7`、分割线 `#E4E4E7`、控件底 `#FFFFFF`、画布 `#1C1C1E`、主文字 `#1D1D1F`、次文字 `#6E6E73`、强调 `#0A7CFF`、危险 `#E5484D`
深色：chrome `#2A2A2D`、分割线 `#3A3A3D`、控件底 `#3A3A3D`、画布 `#101012`、主文字 `#F5F5F7`、次文字 `#A1A1A6`、强调 `#0A84FF`、危险 `#FF6961`

## 实现状态

版式 A 已落地（随 v1.0 开发），与设计稿的对应关系：

- `ui.rs`：52 px 工具栏、30×30 图标按钮、118×30 分段缩放、`⋯` 溢出菜单（主题、色彩标记、日志、快捷键、删除/定位/复制）、26 px 单行状态栏、内联红色错误横幅。
- `thumbs.rs`：条高 88、卡片 76×56、圆角 6、间距 9，选中为外扩 2 px 强调色环；未打开目录或关闭开关时整条隐藏。
- `viewer.rs`：空状态为图标 + 标题 + 说明 + 强调色主按钮；画布恒为深色；适配模式四周留 5% 边距。
- `theme.rs` / `settings.rs` / `app.rs`：主题设置（跟随系统 / 浅色 / 深色），窗口 chrome 随主题切换，画布固定深色；主题与缩略图条开关均持久化。
- 全屏时文件名回到工具栏中央，3 秒后淡出；窗口标题简化为 `文件名 — 图片查看器`。

未实现（有意保留）：

- 版式 B 的 `muda` 原生菜单栏（Windows/macOS）。次级操作统一收在 `⋯` 与右键菜单中；如后续需要，可另加“菜单栏：系统原生 / 只用工具栏”设置项。
