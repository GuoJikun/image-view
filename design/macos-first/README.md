# 界面设计规范 · macOS 优先（三端和谐）

> 设计稿与规格。配套高保真效果图见 `mockup.html`（浏览器直接打开，含 8 个场景切换）。
> 本稿以**代码现状**（`apps/eframe-app/src/`）为功能基线重新设计视觉语言：以 macOS（Sonoma / Sequoia 风格）为参考基准，同时保证 Windows、macOS、Linux 三端观感和谐。
> 与 `design/redesign`（版式 A，已落地）的关系：**功能布局沿用版式 A**，本稿升级视觉语言与外壳策略（macOS 原生标题栏 / Win·Linux 自绘标题栏、胶囊分段控件、macOS 式菜单、分平台字体栈）。

## 一、设计原则

1. **一套内容语言，三套窗口外壳。** 窗口内部（工具栏、画布、缩略图条、状态栏、菜单、弹窗）在三端使用完全相同的尺寸、圆角与配色；窗口外壳按平台分工：**macOS 用原生标题栏，Windows / Linux 自绘标题栏**。用户在任一平台学会操作，另两个平台零迁移成本。
2. **macOS 为基准值，不做平台风格拼贴。** 控件尺寸、圆角、间距、层级以 macOS HIG 为基准（如 Body 13 px、控件圆角 6、菜单圆角 10）。Windows / Linux 上**不改基准值**，不换成 Fluent 或 Adwaita 的控件造型——三端渲染结果因此天然接近。平台差异只体现在窗口标题栏的绘制来源与字体渲染，不体现在控件本身。
3. **克制的材质与单一强调色。** 视觉质感来自「浅灰 chrome + 发丝线 + 单一强调色 + 极轻投影」，不使用平台专有材质（Mica / 亚克力 / GNOME 橙）。强调色仅用于选中、主按钮、进度与开关；其余靠中性灰明度分层。
4. **画布恒为深色。** 图片是主角：无论浅色/深色主题，画布固定 `#1C1C1E`（深色 `#101012`），保证图片始终有最大对比度（沿用版式 A 不变）。

## 二、布局解剖：标题栏 + 工具栏 两段式

三端统一为「**标题栏 28 px + 工具栏 52 px**」两段式结构。标题栏的绘制来源按平台分工——macOS 原生、Windows / Linux 自绘——高度对齐（macOS 原生标题栏为 28 px），保证三端窗口总高与控件节奏一致：

```
┌─ 标题栏 28 px ──────────────────────────────────────────┐
│ (红绿灯)              sunset.jpg — 图片查看器             │  macOS：系统原生（窗口内无菜单栏）
│ 文件 显示 帮助        sunset.jpg — 图片查看器     [—][▢][✕] │  Windows / Linux：自绘 + VS Code 式菜单栏
├─ 工具栏 52 px（三端逐像素一致）──────────────────────────────┤
│ [打开] │ ‹ ›              [◫][▶][名称▾] │ [− 100% +] │
├─────────────────────────────────────────────────────────┤
│                       画布（恒为深色）                     │
├─────────────────────────────────────────────────────────┤
│  缩略图条 88 px（可隐藏）                                   │
├─────────────────────────────────────────────────────────┤
│  状态栏 26 px                                             │
└─────────────────────────────────────────────────────────┘
```

macOS 屏幕顶部另有**系统菜单栏**（  图片查看器 · 文件 · 显示 · 帮助），窗口内不重复绘制。

- **标题栏（28 px）**：文件名居中（13 px semibold，中段省略号截断）。
  - **macOS**：系统原生标题栏——红绿灯、拖拽、双击缩放、全屏由系统提供，不自绘、不隐藏、不改色（仅随系统浅/深色）。
  - **Windows**：自绘——**VS Code 式菜单栏居左**（`文件` `显示` `帮助`，12.5 px 文本项），右侧 caption 按钮 46 × 28（Win11 glyph，悬停仅关闭键变红 `#C42B1C`）；拖拽 / 双击最大化 / 边缘缩放走 `ViewportCommand`。
  - **Linux**：自绘（现状延伸）——同样带 VS Code 式菜单栏居左，右侧圆形三钮 26 × 28，窗口圆角 8、四角透明；交互同 Windows。
- **工具栏（52 px，三端一致）**：左侧 `打开` + 分隔线 + `‹ ›`；右侧 `缩略图` `幻灯片` `排序▾` ｜ 胶囊缩放 `− 百分比 +`。工具栏**不显示文件名**（标题栏已显示），**不再有 `⋯` 溢出按钮**——次级操作全部收入菜单栏（见 4.5）。
- **全屏**：标题栏隐藏（macOS 由系统接管；Win/Linux 自绘条整体淡出），文件名回到工具栏中央，3 秒后淡出（沿用现状）。

强调色沿用 Apple system blue（深色变体），三端同一值，不跟随平台强调色，避免「同一份截图三端三种蓝」。

### 3.2 字体

三端字号/字重完全一致，仅字体族按平台取系统 UI 字体（渲染协调、字重映射一致）：

| 用途 | 字号 / 字重 | macOS | Windows | Linux |
| --- | --- | --- | --- | --- |
| 窗口标题（标题栏文件名） | 13 / semibold(590) | SF Pro Text | Segoe UI Variable Text | Inter |
| Body（菜单、弹窗正文） | 13 / regular | SF Pro Text | Segoe UI | Noto Sans |
| Button / 控件标签 | 12.5 / regular | SF Pro Text | Segoe UI | Noto Sans |
| Small（状态栏、辅助） | 11 / regular | SF Pro Text | Segoe UI | Noto Sans |
| Heading（弹窗标题、空状态标题） | 15 / semibold | SF Pro Display | Segoe UI Variable Display | Inter |

CSS 字体栈（自绘渲染同序）：

```css
--font-ui: -apple-system, "SF Pro Text", "PingFang SC",
           "Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI",
           "Inter", "Noto Sans CJK SC", "Noto Sans", sans-serif;
```

数字（缩放百分比、状态栏尺寸/序号）启用 **tabular-nums**，翻页时不抖动。

### 3.3 形状、间距、投影

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `radius-control` | 6 | 图标按钮、分段控件、排序按钮、输入/勾选框 |
| `radius-menu` | 8 | 菜单 / 右键菜单 / 弹出层 |
| `radius-window` | 10 | 弹窗；窗口本体（macOS/Linux，贴边时归 0） |
| `radius-tile` | 8 | 缩略图卡片（比控件略圆，呼应 macOS 预览缩略图） |
| 间距基数 | 4 px | 所有内/外边距取 4 的倍数（8 / 12 / 16 / 24） |
| 发丝线 | 1 px | 分隔线、控件描边，永不用 2 px |
| 投影-popover | `0 8 24 rgba(0,0,0,.18)`（深色 `.45`） | 菜单、弹出层 |
| 投影-selected | `0 2 8 rgba(0,0,0,.22)` | 缩略图选中卡、分段控件选中块 |

### 3.4 动效

| 场景 | 时长 / 缓动 |
| --- | --- |
| 菜单/弹出层 | 120 ms，`ease-out`，自 0.96 缩放 + 4 px 下移淡入 |
| 按钮悬停/按下 | 60 ms 背景交叉淡入 |
| 全屏文件名 | 淡入 200 ms，停留 3 s，淡出 400 ms |
| 状态栏短提示 | 停留 4 s，淡出 300 ms |
| 缩略图条收起/展开 | 180 ms 高度动画 |

## 四、组件规格

### 4.1 工具栏（52 px）

- 左右内边距 12 px（三端一致）。
- **图标按钮** 30 × 30，圆角 6，图标 17 px、线宽 1.5；悬停 `hover` 底，按下 `press` 底，激活（如缩略图开启、幻灯片运行）用 `accent-soft` 底 + `accent` 图标；禁用 `text3`。
- **分隔线** 1 × 18，两侧各 12 px。
- **排序按钮**：12 px 文本 + 12 px 下箭头，高 30、圆角 6，宽度随文字。
- 工具栏**无 `⋯` 溢出按钮**：次级操作（定位、复制路径、删除、主题、语言、更新、日志等）全部收入菜单栏（见 4.5），工具栏只保留高频直接操作。
- 全屏时（标题栏隐藏）文件名淡入工具栏中央，3 s 后淡出；平时工具栏不显示文件名。

### 4.2 缩放分段控件（胶囊）

118 × 30，**整体为胶囊形**（轨道圆角 7）：

- 轨道：`track` 填充 + 1 px `hairline` 描边。
- 中段「值」块：白底（深色 `control`）圆角 5，1 px 描边 + 投影-selected，点击 = 适配窗口。
- 左右 `−` / `+` 各占 1/3，悬停在各自区域内出现圆角 4 的 `hover` 底。
- 值文本 12 px tabular-nums；无图片显示 `—` 并禁用。

### 4.3 缩略图条（88 px）

- 条底 `strip`，上缘 1 px 发丝线；卡片 **76 × 56、圆角 8、间距 9**，上下居中（上下各 16 px）。
- 卡片底 1 px `hairline` 描边；悬停 `hover` 底；**选中：外扩 2 px `accent` 环 + 投影-selected**。
- 懒加载 + 虚拟滚动（沿用现状）；当前项自动居中。

### 4.4 状态栏（26 px）

- 11 px，`text2` 主信息 / `text3` 副信息，间隔用 `·`（`text3`）。
- 左侧：`尺寸 · 位深 · 格式 · 色彩标记`；降采样警告用 `#E6A032`。
- 右侧：短提示（`success`）→ 幻灯片标记 → `序号 / 总数`（tabular-nums）→ 加载 spinner。
- 与画布间 1 px 发丝线；上缘线只画在缩略图条隐藏时（有条时条自身已有线，避免双线）。

### 4.5 菜单（macOS 原生 / Windows·Linux 学习 VS Code）

三端菜单**内容与信息架构完全一致**（同样的三个菜单、同样的分组顺序），绘制方式分两套：

**macOS —— 系统原生菜单栏**

- 菜单走屏幕顶部系统菜单栏（  图片查看器 · 文件 · 显示 · 帮助），窗口内不绘制菜单；下拉由系统绘制，不自绘、不改样式。
- 遵循原生规范：勾选/单选在**左侧**，快捷键右对齐且使用 `⌘ ⌥ ⇧` 符号，子菜单箭头 `›` 在右。

**Windows / Linux —— VS Code 式菜单**

- **菜单栏**：居标题栏左侧，文本项 `文件` `显示` `帮助`，12.5 px、项高 28（占满标题栏）、左右内边距 8；悬停 `hover` 底，展开时 `accent-soft` 底 + `accent` 文字；Alt 键可切换显示/隐藏（VS Code 行为，P3）。
- **下拉面板**：底 `control`、圆角 6、投影-popover、内边距 5；菜单项高 26、圆角 4。
  - **左侧 22 px 图标槽**：勾选/单选放这里（✓ / •，**左对齐**——与 macOS 原生一致）；无状态项留空。
  - 标签 13 px `text`；**快捷键右对齐** 12 px `text3`（`Ctrl+Shift+C` 形式）、tabular-nums。
  - 悬停/选中：整行 `accent` 填充 + 白字（含快捷键列）；危险项文字 `danger`（悬停时仍为 accent 填充）。
  - 分隔线 1 px，左侧内缩 30 px（对齐标签起点）；子菜单右端 `›`。

**菜单内容（三端一致，承接原 `⋯` 全部条目）**

| 菜单 | 条目 |
| --- | --- |
| 文件 | `打开图片…` Ctrl+O ｜ ─ ｜ `在文件管理器中显示`、`复制路径` Ctrl+Shift+C ｜ ─ ｜ `移到废纸篓` Delete（danger） |
| 显示 | `缩略图条` ✓、`幻灯片` Space ｜ ─ ｜ `排序 ▸`（按名称 ✓ / 按修改时间）｜ ─ ｜ `放大` +、`缩小` −、`适配窗口` 0、`实际大小` 1 ｜ ─ ｜ `主题 ▸`（跟随系统 ✓ / 浅色 / 深色）、`语言 ▸`（跟随系统 ✓ / 简体中文 / English）｜ ─ ｜ `显示色彩转换标记` ✓ |
| 帮助 | `快捷键…`、`检查更新…`、`启动时检查更新` ✓ ｜ ─ ｜ `打开日志文件夹`、`第三方许可证` |

### 4.6 空状态

画布中央：图标 60 × 60（`text3`）→ 标题 15 semibold（`text`）→ 说明 12 `text2` → 主按钮（`accent` 填充、白字、高 28、圆角 6、水平内边距 16）。整体垂直居中偏上 24 px（避开缩略图条视觉重心）。

### 4.7 错误横幅

内联在工具栏下方：底 `danger-soft`，左侧 3 px `danger` 竖条，警告图标 14 + 11.5 px 文本（`danger_text`），右端 `重试` / `关闭` 无边框文字按钮。不遮挡画布图片区，用户可继续看图。

### 4.8 弹窗（帮助 / 检查更新）

- 宽 460（帮助 400），圆角 10，标题 15 semibold；内容内边距 16。
- 按钮行右对齐：主按钮（accent 填充）在左、次按钮（普通）在右，按钮高 28、圆角 6。
- 进度条高 6、胶囊形，轨道 `track`、填充 `accent`。
- 快捷键帮助改为两列「按键 + 说明」，按键用 12 px 等宽、圆角 4 的键帽样式（`track` 底 + 1 px 描边）——三端一致，仅 macOS 键帽符号用 `⌘ ⌥ ⇧`。

## 五、三端外壳适配矩阵

| 项 | macOS | Windows | Linux |
| --- | --- | --- | --- |
| 标题栏 | **系统原生**（红绿灯 / 拖拽 / 双击缩放 / 全屏均系统提供） | **自绘 28 px**：caption 按钮 46 × 28 右上 | **自绘 28 px**：圆形三钮右上（现状） |
| 标题栏高度 | 28（系统常量） | 28（对齐 macOS） | 28（对齐 macOS，现状 32 → 28） |
| 窗口圆角 | 系统常量 | 系统默认（Win11 自动圆角） | 8（现状，透明角） |
| 工具栏 52 px | 自绘，三端一致 | 同左 | 同左 |
| 菜单栏 | **系统原生菜单栏**（ 图片查看器 / 文件 / 显示 / 帮助），窗口内不绘制 | **VS Code 式**：标题栏左侧文本项 + 自绘下拉 | 同 Windows（VS Code 式） |
| 文件名位置 | 原生标题栏居中 | 自绘标题栏居中 | 自绘标题栏居中 |
| 快捷键提示 | `⌘ ⌥ ⇧` 符号 | `Ctrl / Alt / Shift` | `Ctrl / Alt / Shift` |

| 缩放默认 | 跟随系统（Retina 按物理像素） | 跟随系统 DPI | 跟随 `pixels_per_point` |
| 删除语义 | 移到废纸篓（"移到废纸篓"） | 移到回收站 | 移到回收站（`gio trash`） |

**和谐性说明**：三端均为「标题栏 28 + 工具栏 52」两段式，文件名一律在标题栏居中，工具栏内容逐像素一致；差异只有「标题栏是系统画还是自己画、窗口按钮造型、字体怎么渲染」——macOS 保留原生标题栏是平台惯例的底线（用户期待红绿灯与系统全屏行为），Windows / Linux 自绘则换来三端高度与文字位置的严格对齐。刻意不做的事：Windows 不用 Mica 材质、Linux 不用 Adwaita 按钮造型、macOS 不把红绿灯挪进工具栏——任何一端的「过强平台味」都会破坏三端并排时的和谐。

## 六、体验优化清单（增量建议）

在标题栏策略与视觉语言之外，以下优化按「收益 / 成本」排序，可随版本分批落地：

| # | 优化点 | 说明 | 建议阶段 |
| --- | --- | --- | --- |
| 1 | **拖放打开反馈** | 文件拖入时画布叠加强调色 2 px 内描边 + 半透明蒙层，居中提示「松开以打开」；松开后立即进入加载态 | P2 |
| 2 | **图片切换过渡** | 翻页时旧图 120 ms 淡出、新图 160 ms 淡入（或交叉淡化），消除快速翻页的闪黑/闪灰 | P2 |
| 3 | **全屏自动隐藏工具栏** | 全屏后工具栏 1.5 s 淡出，鼠标移至窗口顶部或按任意修饰键唤出；与文件名 3 s 淡出错峰 | P2 |
| 4 | **Tooltip 规范** | 统一 macOS 式提示：圆角 5、深底浅字（深色主题反转）、延迟 400 ms 出现；快捷键按平台符号化后缀在提示尾部 | P2 |
| 5 | **键盘焦点环** | Tab 遍历工具栏 / 菜单 / 弹窗按钮时显示 2 px 强调色外环（偏移 2 px）；Esc 逐层退出（已有）保持不变 | P3 |
| 6 | **窗口最小尺寸** | 限制 720 × 520，防止缩略图条 + 状态栏 + 工具栏挤压崩版；小于阈值时先隐藏缩略图条 | P1 |
| 7 | **错误横幅自动收起** | 8 s 后自动折叠为顶栏下方 24 px 细条（保留红点标记），点击可展开；避免长时间遮挡视线 | P3 |
| 8 | **缩略图条滚动动画** | 当前项居中采用 180 ms 平滑滚动；拖动条惯性滚动与触控板自然一致 | P3 |
| 9 | **画布 / chrome 分界线** | 深色主题下画布与缩略图条之间补 1 px `#000`（10% 透明度）分界，防止深色块「糊」在一起 | P1 |
| 10 | **加载骨架** | 首次打开大图时画布中央显示低对比 spinner + 图片尺寸占位文本（复用状态栏信息），替代纯黑等待 | P3 |
| 11 | **Alt 显隐菜单栏**（Win/Linux） | 按 Alt 切换标题栏内菜单栏的显示（VS Code 行为），给文件名释放空间；再按任一菜单项快捷键可直接唤出 | P3 |

> 高对比度 / 减少动效（`prefers-reduced-motion`）等辅助能力统一在 P3 的可访问性专项中处理。
