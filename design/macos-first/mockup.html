体验优化清单（增量） 按收益 / 成本排序，随版本分批落地

P1

P2

P2

P2
全屏自动隐藏工具栏 —— 1.5 s 淡出，鼠标移至顶部唤出；与文件名 3 s 淡出错峰
P2
Tooltip 规范 —— macOS 式提示（圆角 5、深底浅字、延迟 400 ms），快捷键符号按平台后缀
P3
